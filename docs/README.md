# GOAT Flow documentation

For a first application integration, follow the
[Developer Quick Start](goat-flow-developer-quickstart.md). You do not need to
read every page first.

| Page | Open it when you need to… |
| --- | --- |
| [Developer Quick Start](goat-flow-developer-quickstart.md) | Create a session, open checkout, and confirm a crypto payment |
| [Merchant Guide](merchant-guide.md) | Register, configure payment methods, or operate the portal |
| [API Reference](goat-flow-api-reference.md) | Look up fields, authentication, environments, versions, or retry behavior |
| [Troubleshooting](goat-flow-faq.md) | Resolve an error or an unexpected payment state |
